# Buddy Flash App

Runpod Flash endpoints for Buddy's accessibility evidence pipeline.

## Endpoints

- `buddy-extract-accessibility-claims`
- `buddy-score-accessibility-status`
- `buddy-plan-call-questions`
- `buddy-parse-voice-transcript`
- `buddy-generate-local-render-payload`

Build locally with:

```bash
flash build --no-deps
```
